# Лабораторная работа 2. Сигналы и слоты (PyQt5)

Окно-конвертер валют: **доллар — рубль — евро**
При изменении любого из трех полей остальные два пересчитываются автоматически

Условные курсы

- `1 USD = 90 RUB`
- `1 EUR = 100 RUB`

1. **Стандартные сигналы Qt → слоты.**
   У каждого `QLineEdit` сигнал `textChanged` подключен к своему слоту-обработчику
   (`on_usd_changed`, `on_rub_changed`, `on_eur_changed`)

2. **Защита от рекурсии через `blockSignals`.**
   Когда слот обновляет чужое поле, у него тоже срабатывает `textChanged`.
   Чтобы не уйти в бесконечный цикл, обновление идёт через `_set_silently()`:
   `blockSignals(True)` → `setText()` → `blockSignals(False)`

3. **Собственный сигнал `pyqtSignal`.**
   Внутри класса объявлен свой сигнал `valueChanged = pyqtSignal(str)`.
   После пересчёта он испускается (`emit`) с именем поля-источника,
   а подключённый к нему слот `log_change` обновляет метку «Журнал».
