# Основы проектирования графического интерфейса компьютерных систем
# Лабораторная работа 1

## Программа реализует базовое графическое окно на PyQt5
- текстовую метку (QLabel)
- кнопку (QPushButton)
- логику замены текстового содержимого метки на загруженное изображение по клику

## Функционал
- При запуске отображается окно с надписью и кнопкой
- По нажатию на кнопку программа проверяет наличие файла изображения в директории
- Файл найден - загружается и отображается с сохранением пропорций
- Файл не найден/ошибка загрузки -  сообщение об ошибке
- Поддерживаются изображения с прозрачностью
